## 归档方式

- 同一门课程的资料放在一起：资料少时使用一个 Markdown 文件，资料较多时再建立课程子文件夹。
- 文件名说明主题；按时间整理的课堂笔记，可使用 `YYYY-MM-DD-主题.md`。
- 添加、改名或删除资料后，同步更新本页的课程目录。
