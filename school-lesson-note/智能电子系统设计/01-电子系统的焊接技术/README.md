# 01-电子系统的焊接技术：题目与答案

> 来源：学习通「作业详情」页面。共 8 题，其中单选题 5 题、多选题 3 题，满分 100 分，每题 12.5 分。
> 整理日期：2026-10-22。标准答案按页面显示收录；解析为后续补充的复习说明，非教师原解析。保留原题页码提示。

## 一、单选题

### 1. 对于我们平时焊接所用的焊锡丝，描述正确的是______？（P2）

- A. 焊锡丝是实心的焊锡组成。
- B. 焊锡丝是空心的，中间添加助焊剂
- C. 焊锡丝是空心的，中间是空气。

**正确答案：B。焊锡丝是空心的，中间添加助焊剂。**

**解析：** 本题指常见的药芯焊锡丝：外层是焊料，内部含助焊剂。助焊剂有助于清除氧化物，让熔化的焊料更容易润湿金属表面。“空心”不是指里面装空气。市面上也有实心焊锡丝，不能把本题说法理解为所有焊锡丝都一样。

**记忆：** 药芯焊锡丝，芯里有助焊剂。

### 2. 焊接后导致元器件烧毁，最可能的原因是______？（P2）

- A. 烙铁头在一个焊点焊接时用力过猛
- B. 烙铁头在一个焊点停留时间太短
- C. 烙铁头在一个焊点停留太久，且温度过高

**正确答案：C。烙铁头在一个焊点停留太久，且温度过高。**

**解析：** 烙铁的热量会经引脚传到元器件内部。温度过高、停留太久，容易造成热损伤，因此选 C。用力过猛主要可能损伤焊盘；加热太短则更容易导致焊料润湿不足、焊接不牢。

**记忆：** 太热太久伤元件，太短容易焊不牢。

### 3. 烙铁头的保养与维护中，烙铁头氧化、黑化的“最重要”原因是______？

- A. 通电时间长
- B. 未使用高档焊锡丝
- C. 不挂锡保养，长时间暴露在空气中
- D. 未定期清理烙铁头碳化物

**正确答案：C。不挂锡保养，长时间暴露在空气中。**

**解析：** 烙铁头在高温下接触空气容易氧化。挂锡就是让工作面覆盖一层焊料，减少直接接触空气。A、D 也可能影响烙铁头状态，但本题更强调“不挂锡、长时间暴露”这一直接原因；不是买贵焊锡就能解决。

**记忆：** 烙铁头怕“高温裸露”，不用时也要注意挂锡。

### 4. 使用烙铁焊接的正确步骤是______？（P2）

题目给出的步骤：

1. 焊点加助焊剂，烙铁接触后加焊锡
2. 挂锡保养烙铁头
3. 海绵清洁烙铁头再放入助焊剂保护烙铁头
4. 接通电源待温度升高

选项：

- A. 2-3-4-1
- B. 4-3-2-1
- C. 4-2-3-1
- D. 1-2-3-4

**正确答案：B。4-3-2-1。**

**解析：** 按题目给出的步骤，先通电升温（4），再清洁烙铁头（3），接着挂锡（2），最后对焊点进行焊接（1），所以选 B。

**操作补充：** 本题步骤是简化描述。“放入助焊剂保护”不能代替挂锡，也不是要求把烙铁头浸入任意助焊剂。实际焊接要同时加热焊盘和引脚，再送入焊锡；暂停或结束后也要挂锡保护工作面。

**记忆：** 升温 → 清洁 → 挂锡 → 焊接。

### 5. 电烙铁的工作原理是将____能量，转换为____能量？（P1）

- A. 化学能，热能
- B. 电能，热能
- C. 电能，化学能

**正确答案：B。电能，热能。**

**解析：** 电烙铁通电后，发热元件把电能转化为热能，再将热量传给烙铁头，用来熔化焊料。因此是“电能 → 热能”，不涉及把电能变成化学能。

**记忆：** 电烙铁：电变热。

## 二、多选题

### 6. 烙铁头不沾锡的原因有______？（P3）

- A. 烙铁已损坏
- B. 烙铁手握姿势不对
- C. 烙铁头已严重氧化
- D. 长时间通电，不挂锡保养烙铁头，且温度过高

**正确答案：A、C、D。**

- A. 烙铁已损坏
- C. 烙铁头已严重氧化
- D. 长时间通电，不挂锡保养烙铁头，且温度过高

**解析：** 不沾锡就是熔化的焊锡不能良好铺展、附着在烙铁头工作面上。设备或烙铁头损坏可能造成温度或表面状态异常（A）；严重氧化会妨碍润湿（C）；长时间高温通电又不挂锡，会加重氧化（D）。握姿不对影响操作，但通常不是工作面不沾锡的直接原因。

**记忆：** 查损坏、查氧化、查高温空烧。

### 7. 焊接完成后，如何通过观察法，避免虚焊或假焊______？（P3）

- A. 焊点上的焊锡量宜多不宜少
- B. 焊点应为半球状
- C. 焊点外表光滑、均匀
- D. 没有明显的气泡、凹陷

**正确答案：B、C、D。**

- B. 焊点应为半球状
- C. 焊点外表光滑、均匀
- D. 没有明显的气泡、凹陷

**解析：** 按本作业标准答案选 B、C、D，主要考查焊点外观完整、表面均匀、没有明显缺陷。A 错在“宜多不宜少”：焊锡应适量，过多可能形成锡球或连锡，也会遮住实际连接情况。

**实际操作补充：** “半球状”不是所有合格焊点的通用标准。常见通孔焊点通常应看到焊料润湿焊盘和引脚，形成向内弯的焊脚；正常的凹弧面不能与缺陷性的凹坑混为一谈。外观检查有助于发现问题，但不能保证完全没有虚焊。

**记忆：** 锡量适中、润湿良好、无明显缺陷；本题记 BCD。

### 8. 使用烙铁焊接的注意事项有哪些？（ ）（P2）

- A. 选择合适的焊锡丝和助焊剂
- B. 烙铁头挂锡保养
- C. 焊接前先洗手
- D. 正确的姿势

**正确答案：A、B、D。**

- A. 选择合适的焊锡丝和助焊剂
- B. 烙铁头挂锡保养
- D. 正确的姿势

**解析：** 合适的焊锡丝和助焊剂有利于焊接（A）；挂锡能保护烙铁头工作面（B）；正确握姿有利于控制接触位置、时间和送锡动作（D）。C 属于一般卫生习惯，不是本题考查的焊接技术要点，因此按页面答案不选；这不代表可以忽视清洁卫生。

**记忆：** 材料选对、挂锡保养、姿势正确。
